Практические примеры настройки:
Если AKM "прыгает" вверх:
⬇️ INT с 7 на 6 (компенсация чаще)
⬆️ KICK с 1.42 на 1.50 (мощнее первый выстрел)
⬆️ TIME с 165 на 175 (дольше держит)

Если MP5K "переусложняется":
⬆️ INT с 8 на 9 (компенсация реже)
⬇️ KICK с 1.20 на 1.15 (мягче первый выстрел)
⬇️ SMF с 0.50 на 0.45 (плавнее реакция)

Краткая памятка:
Сильное оружие = INT ⬇️ + KICK ⬆️ + TIME ⬆️ + SMF ⬆️
Слабое оружие = INT ⬆️ + KICK ⬇️ + TIME ⬇️ + SMF ⬇️

Сравнительная таблица:
Характеристика	Сильная отдача	Слабая отдача
INT	⬇️ 7-9 (быстро)		⬆️ 8-10 (редко)
KICK	⬆️ 1.4-1.48 (мощный)	⬇️ 1.12-1.20 (мягкий)
TIME	⬆️ 150-172 мс (долго)	⬇️ 110-125 мс (коротко)
SMF    	⬆️ 0.65-0.70 (быстрая)	⬇️ 0.42-0.50 (плавная)

Основные параметры калибровки (F6 — переключение)
Клавиши F7/F8 ( Уменьшит/увеличит)
1	RCL (Recoil)	±0.1	Основная сила отдачи для текущего прицела
2	INT (Interval)	±1 мс	Интервал срабатывания компенсации (для авто)
3	KICK	±0.02	Мощность первого выстрела
4	TIME	±5 мс	Длительность усиленного первого выстрела 
5	DMR	±5 мс	Интервал для самозарядных (M16A4, SLR, Mk12 и т.д.) 
6	SMF (Smooth Factor)	±0.05	Плавность компенсации (0.10 = максимальная гладкость, 1.0 = моментальная)
