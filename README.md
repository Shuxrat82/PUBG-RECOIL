КАК ВКЛЮЧИТЬ МАКРОС
1️⃣ ОСНОВНОЙ ЗАПУСК
Требования:
✅ Установлен AutoHotkey v2.0+
✅ Windows 10/11
✅ Запуск от администратора
Способ 1: Прямой запуск
Код
1. Скачать файл: PUBG_Recoil_Macro 22.ahk
2. Кликнуть правой кнопкой мыши
3. Выбрать "Run as administrator" (Запустить от имени администратора)
4. Появится консоль AutoHotkey
Способ 2: через AutoHotkey IDE
Код
1. Открыть AutoHotkey v2.0
2. File → Open → выбрать файл макроса
3. Tools → Run Script (Запустить скрипт)
2️⃣ АКТИВАЦИЯ МАКРОСА В ИГРЕ
✅ Основная комбинация:
Код
Ctrl + CapsLock = ВКЛЮЧИТЬ/ОТКЛЮЧИТЬ макрос
Что происходит при включении:

🎵 Звук 1200 Гц (писк)
🔴 Оверлей становится ВИДИМЫМ в правом верхнем углу
📊 Статус: ● ON (зеленый)
При отключении:

🎵 Звук 400 Гц (низкий писк)
🔴 Оверлей скрывается
📊 Статус: ● ВЫКЛ (красный)
3️⃣ ИНТЕРФЕЙС МАКРОСА


┌─────────────────────────────────────────────────────────────┐
│ ● ON  │ M416 (1x) │ R:1.9 │ STAND │ CAL:RCL=1.9           │
└─────────────────────────────────────────────────────────────┘
  ↑      ↑           ↑       ↑       ↑
  │      │           │       │       └─ Параметр калибровки
  │      │           │       └─────── Стойка персонажа
  │      │           └────────────── Сила отдачи
  │      └────────────────────────── Оружие + прицел
  └─────────────────────────────────── Статус (ON/OFF)
  
Значения в интерфейсе:
Параметр	шотландский	Я
● ВКЛ/ВЫКЛ	Зеленый/Красный	Макрос включен/отключен
М416	Имя оружия	Текущее выбранное оружие
(1x)	1x, 2x, 3x, 4x, 6x	Текущий прицел
Р:1.9	0,1 - 20,0	Сила отдачи
СТОЯТЬ	СТОЯ/ПРИСЕДАНИЕ/ПОЛОЖЕНИЕ ЛЁЖОМ	Стойка персонаж
CAL:RCL=1.9	RCL/INT/KICK/TIME	Параметр результата
4️⃣ ГОРЯЧИЕ КЛАВИШИ
Выбор оружия:
Код
Numpad 1 = M416          Numpad 6 = G36C
Numpad 2 = ACE32         Numpad 7 = QBZ
Numpad 3 = AKM           Numpad 8 = GROZA
Numpad 4 = M762          Numpad 9 = AUG
Numpad 5 = SCAR-L        Numpad 0 = FAMAS
Листание оружий:
Код
Numpad + = Следующее оружие
Numpad - = Предыдущее оружие
Переключение прицелов:
Код
Numpad / = Следующий прицел
Numpad * = Предыдущий прицел
Регулировка отдачи:
Код
Home    = УВЕЛИЧИТЬ компенсацию (+0.1)
Delete  = УМЕНЬШИТЬ компенсацию (-0.1)
Калибровка:
Код
F6 = Переключить параметр калибровки
     (RCL → INT → KICK → TIME → RCL...)

F7 = УМЕНЬШИТЬ текущий параметр
F8 = УВЕЛИЧИТЬ текущий параметр
Детектор стойки персонажа:
Код
C = Toggle STAND ↔ CROUCH
Z = Toggle STAND ↔ PRONE
Space = PRONE → STAND (прыжок)
F5 = Сброс в STAND
Режимы съемки:
Код
K = Toggle режим RMP (левая кнопка мыши → XButton2)
    ● OFF = обычная стрельба
    ● ON  = автоклик
Экстренные команды:
Код
Ctrl + Shift + Q = ВЫХОД из макроса
Ctrl + Shift + R = ПЕРЕЗАГРУЗКА скрипта
